# Дизайн-система Оптимы 0.3

## Структура экрана

Постоянная вертикальная навигация и верхняя панель банка. Заголовок раздела содержит его основные действия. В предложениях список и финансовый расчёт располагаются рядом: выбор строки не уводит со страницы и не сбрасывает введённый объём. На небольшом экране строка открывает условия в полноэкранной панели.

Только четыре работающих раздела: предложения, закупки, потребности и аналитика. Контекст компании и деморежим видны постоянно.

## Роли

| Роль | Решение |
| --- | --- |
| Основное действие | Сплошная синяя кнопка, высота 44–48 px |
| Дополнительное действие | Белая кнопка с нейтральной границей |
| Переход или уточнение | Текстовая ссылка с направлением |
| Текущий раздел | Постоянный подвижный индикатор в навигации |
| Выбранная закупка | Синяя кромка, светлая подложка, aria-pressed |
| Цена своего заказа | Крупное число, одинаковая ширина цифр |
| Экономия | Зелёный используется только для положительной разницы |
| Условия и источники | Вторичный текст рядом с соответствующей суммой |

## Токены

Файл `dist/styles/tokens.css` задаёт цвета, интервалы и движение. Основные оттенки и шкала движения опираются на публичные токены Admiral 3, лицензия MIT сохранена в репозитории.

- Основной синий `#0062FF`, наведение `#0046E2`, светлая подложка `#EBF3FF`.
- Навигация в тёмном синем, белые рабочие поверхности, нейтральный фон.
- Интервалы 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px.
- Golos Text: 400 для основного текста, 500 для заголовков и сумм, 600–700 для отдельных акцентов. Шрифт локальный, с кириллицей.
- Заголовок раздела 28–32 px, заголовок компонента 20–22 px, основной текст 13–14 px, подробности 11–12 px. В узких табличных строках часть метаданных компактнее.

## Движение и сохранение состояния

Системная шкала: 150 ms для реакции, 200–250 ms для содержимого, 300–350 ms для навигации и панелей. Ускорение входа `cubic-bezier(0.05,0.6,0.2,1)`; выход короче входа. Непрерывного декоративного движения нет.

Оболочка, навигация и её индикатор не пересоздаются при переходах. Изменение количества обновляет значения и полосу группы на месте. Добавление в избранное сохраняет поле расчёта и введённый объём. Переключение вкладок условий сохраняет саму панель. Закрытие панели имеет отдельный переход, защищённый от быстрого повторного открытия.

Режим `prefers-reduced-motion` отключает движение в CSS и JavaScript. Модальный слой изолирует фокус, блокирует фон через inert и возвращает фокус после закрытия.

## Размеры экрана

| Условие | Поведение |
| --- | --- |
| От 1180 px | Список и закреплённый расчёт рядом |
| До 1179 px | Список на всю ширину, выбор открывает условия |
| До 719 px | Нижняя навигация, более компактные строки |

Высота закреплённого расчёта учитывает его положение в окне, прокрутку, изменение размера и загрузку шрифта. Нижнее действие остаётся в видимой части панели; содержимое может прокручиваться внутри неё.

## Файлы

- `dist/styles/tokens.css`: общие токены и шрифты.
- `dist/styles.css`: оболочка, список, расчёт и адаптивность.
- `dist/styles/workflows.css`: базовые элементы заявок, форм, диалогов и таблиц.
- `dist/js/motion.js`: короткие переходы и уменьшение движения.
- `dist/js/app.js`: компоненты и состояние рабочих сценариев.

Проверки DOM не подтверждают точность пикселей или качество движения. Визуальная проверка в браузере остаётся отдельным этапом, заблокированным инфраструктурой предпросмотра в данной среде.

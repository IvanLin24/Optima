# Оптима. Фронтенд совместных закупок

Интерактивный прототип раздела бизнес-банкинга в визуальном направлении ВТБ. Продукт объединяет подтверждённые потребности компаний, сравнивает индивидуальную стоимость закупки и позволяет согласовать участие в группе.

Это самостоятельная концепция для Академии Финтеха. Сайт не является официальным сервисом ВТБ. Реальные счета, платежи, банковская подпись и блокчейн не подключены. Все демонстрационные компании, условия и цены вымышлены.

## Быстрый запуск

Полностью распакуйте архив. В Windows откройте `START_WINDOWS.bat`. Нужен Python 3. Браузер откроется автоматически; окно сервера нужно оставить открытым. В macOS: `python3 run_local.py` из папки проекта или `START_MAC.command`.

Не открывайте index.html двойным щелчком: ES-модули требуют локальный HTTP-сервер.

## Запуск

Для приложения не нужны сборка, CDN или npm-зависимости:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. Можно разместить `dist` на любом статическом хостинге. Запуск через file:// не поддерживается из-за ES-модулей.

Для тестов:

```sh
npm ci
npm run check
```

## Работающие сценарии

- Уже открытый сервис «Оптима»: только предложения, мои закупки, потребности и аналитика. Боковое меню на компьютере и вкладки на телефоне ведут в одни и те же рабочие разделы.

- Подборка из шести предложений, поиск, категории, сортировка, избранное.
- Карточка закупки в боковой панели. Изменение количества и немедленный пересчёт стоимости, доставки, экономии и порога группы.
- Сравнение самостоятельной и совместной закупки с объяснением всех сумм.
- Подтверждение версии условий, создание локальной заявки, сохранение после перезагрузки.
- Статусы «Сбор группы», «Объём набран», «Отменена». Отказ и повторное присоединение.
- Потребности: ручное добавление и импорт CSV/JSON с проверкой полей и календарной даты. PDF/OCR не имитируются.
- Сопоставление потребности по наименованию, точной спецификации, единице и сроку. Цена из потребности учитывается при сравнении.
- Аналитика по данным текущей подборки и выгрузка CSV. Экспорт согласованных условий заявки в JSON.
- Уведомления, журнал действий, справка, описание данных, сброс демонстрации.
- Адаптивный интерфейс, клавиатурный фокус, модальные диалоги, режим уменьшенной анимации.

## Структура

- `dist/index.html`, `styles.css`: оболочка и адаптивное оформление.
- `dist/js/app.js`: экраны и взаимодействия.
- `dist/js/data.js`: изолированные демонстрационные данные.
- `dist/js/domain.js`: расчёт и валидация, без зависимости от DOM.
- `dist/js/store.js`: локальное состояние.
- `dist/js/icons.js`: SVG-иконки и иллюстрации товаров.
- `docs/API-CONTRACT.md`: данные и точки подключения сервера.
- `docs/DESIGN-RESEARCH.md`: визуальные источники и границы соответствия.

# Размещение и локальная разработка

Публичное демо: https://optima.casa/. Исходники соответствуют серверному релизу 20261027-v5.

Локальный запуск API описан в README.md. Фронтенд расположен в frontend/ и обращается к /api/v1 с того же адреса. Для полного локального сайта настройте reverse proxy: статика из frontend/, запросы /api/ — к локальному Uvicorn. Не используйте открытие index.html через file://.

Настройки среды создаются из .env.example. Для разработки используйте отдельную SQLite и MAIL_MODE=file. Код регистрации и входа нужно подтверждать явно; не добавляйте обход авторизации.

Для размещения используйте собственные настройки HTTPS, почтового провайдера, PostgreSQL и резервного копирования. Не переносите локальные демонстрационные значения секретов в production. Сохраняйте БД и действующие сессии при обновлении. Реальных платежей и электронной подписи нет.

Конфигурации действующего сервера, адрес VPS, приватные пути и сведения о сторонних сервисах исключены из публичной копии. Не применяйте к действующему серверу универсальные конфигурации без отдельной проверки владельцем.

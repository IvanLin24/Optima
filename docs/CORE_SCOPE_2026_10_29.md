# Простой кабинет и пустой старт

Новый аккаунт не содержит личных закупок, потребностей, задач, адресов, переписки, товаров или предложений поставщика. Документы и разговоры появляются в контексте созданных пользователем участий и заказов. Каталог не содержит встроенных примеров: он пуст до появления заполненных и опубликованных предложений.

Меню покупателя: обзор, закупки, потребности, сообщения, документы. Меню поставщика: заказы, товары, предложения, сообщения, документы. Убраны подпись ВТБ, переходы в карту, аналитику и внутренние задачи из основного меню и поиска. Старые ссылки на эти вспомогательные экраны ведут в обзор соответствующей роли. Backend этих функций и существующие данные не удаляются.

Для прежнего серверного шаблона добавлена однократная очистка при чтении состояния владельцем. По точному совпадению удаляются две исходные потребности, шаблонная задача, два приветственных сообщения и тестовый товар, если на него нет предложений. Дата потребности сверяется с датой создания компании плюс семь дней. Участие и тестовый адрес сбрасываются только при отсутствии признаков последующих действий пользователя. Редактированные записи, собственные сообщения и товары, оформленные заказы и их адреса сохраняются. Из каталога участников убираются только точные исходные виртуальные записи.

Версия состояния `workspaceVersion: 2` предотвращает повторную обработку. Изменение выполняется с CAS по revision; устаревшее сохранение получает 409 и не возвращает очищенный шаблон. Никакие записи глобальных компаний или таблицы района не удаляются.

Проверки: 50 backend-тестов и 15 Node-тестов, сборка фронта. Отдельно проверены отсутствие личных данных в новом аккаунте, однократность очистки, сохранность редактированных записей и завершённых заказов, защита от старой вкладки и пустые состояния фронта. В браузере проверены статические экраны пустого обзора и документов.

Опубликовано в релизе 20261029-core-e387c4. Перед обновлением создана и проверена приватная резервная копия БД; Nginx, секреты, контейнер БД и процесс Telegram WEB proxy сохранены. API готовности и публичные файлы проверены. В существующей авторизованной вкладке проверены пустые обзор, потребности, документы и сообщения; повторный вход не потребовался, состояние сохранено на сервере. В основном меню ровно пять разделов, bank-context отсутствует. Снимок обзора обрезан до начала подвала и не содержит email пользователя: previews/core-scope-2026-10-29/overview.png.

# Проверка — 27 октября 2026

Текущая размещённая версия: 20261027-v5.

- 43 теста прошли локально на SQLite и на отдельной PostgreSQL-базе сервера (70 секунд).
- Ruff: без замечаний. Alembic: расхождений моделей и схемы нет.
- В браузере проверены реальная отправка кода через Resend, вход по коду, исходный дизайн, сохранение и повторная загрузка состояния.
- Карта: проверены 40 предприятий, создание предприятия, потребности и платежа, создание совместной закупки и переходы до поставки, сохранение после перезагрузки. Проверены desktop и mobile.

Данные синтетические. Реальные платежи, электронная подпись и юридическая пригодность документов не проверялись. Нагрузочное тестирование не выполнялось. Тестовая библиотека Starlette сообщает предупреждение о будущем переходе с httpx на httpx2.

Письмо входа: HTML + текстовая версия, фирменный фон и крупный код, адаптивная ширина. Проверены desktop/mobile без горизонтального переполнения. Resend принял обе версии письма; через его API проверены HTML и ссылка кнопки. В новом браузере ссылка заполнила код и убрала fragment из адреса, без автоматического POST подтверждения; явное нажатие завершило вход. Истечение, однократность и привязка к почте сохранены. Внешний вид во всех почтовых клиентах отдельно не проверялся.

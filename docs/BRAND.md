# Оптима — «Переплетение»

Выбранное направление внедрено локально: знак из переплетающихся лент с ромбовидным просветом. Небольшой знак выполнен в SVG; объёмный арт подготовлен из выбранного концепта и сохранён с прозрачным фоном.

- Общий компонент знака: `frontend/product/brand.js`.
- Применение: публичная главная и её подвал, вход/регистрация, общий заголовок кабинетов покупателя и поставщика.
- Вектор для отдельного использования: `frontend/brand/optima-mark.svg`.
- Иконка вкладки: `frontend/brand/optima-favicon.svg`.
- Объёмный арт: `frontend/brand/optima-weave-sculpture.png`.
- Оформление: `frontend/product/brand.css`. Медленное движение арта отключается при reduced motion.

SVG не содержит растровых изображений или внешних ссылок. При вставке в интерфейс знак декоративный, доступное имя задаёт ссылка «Оптима». Для малых размеров используется плоский знак. Объёмный арт не подменяет логотип в навигации. Основной синий — #1558E9; тёмный — #132F50; светлый фон — #F6F5F0.

Сборка выполнена через `node frontend/build.cjs`. Пройдены две проверки границы авторизации (`node --test tests/landing-gate.test.mjs`). В браузере проверены главная и форма входа, квадратные пропорции знака и отсутствие горизонтального переполнения на 320/390/768 px. PNG проверен на настоящий альфа-канал, SVG — на корректность XML. Функции авторизации и сохранения данных не изменялись. На сервер и в GitHub изменение не опубликовано.

# Дизайн-система Оптимы

Обновлена 17 октября 2026. Версия приложения остаётся 0.3.0.

## Задача интерфейса

Предприниматель выбирает товар, указывает свой объём, сравнивает полную стоимость и подтверждает условия участия. Вокруг этого сценария построено рабочее пространство уже открытого банковского сервиса. В навигации четыре действующих раздела: предложения, мои закупки, потребности, аналитика.

Белая оболочка, нейтральный фон, локальные синие акценты. Положение компании, разделов и действий сохраняется между экранами. Верхняя панель показывает контекст компании и деморежим; пояснение о демонстрационных данных доступно на каждой странице.

## Композиция разделов

| Раздел | Основное содержание | Следующий шаг |
| --- | --- | --- |
| Предложения | Карточки товаров или компактный список; поиск, подборки, категория и сортировка | Выбрать позицию и рассчитать свой объём |
| Расчёт | Товар, количество, итог, индивидуальная стоимость, доставка и состояние группы | Перейти к условиям |
| Мои закупки | Сохранённые заявки, номера, количества, суммы и статусы | Открыть согласованные условия или отменить участие |
| Потребности | Таблица собственных товаров, сроков и найденных совпадений | Добавить товар, загрузить список или открыть предложение |
| Аналитика | Возможная экономия, сравнение категорий и полная таблица расчёта | Выгрузить данные |

Каталог и расчёт разделены по назначению. Карточка помогает сравнивать предложения; справа пользователь меняет собственное количество. Сумма карточки всегда подписана объёмом и указанием доставки. Крупная сумма в расчёте относится к введённому пользователем объёму.

Вводная подсказка объясняет объединение заказов на числовом примере из демонстрационных данных. Её можно закрыть. Вид каталога и закрытие подсказки сохраняются после перезагрузки, заявки и потребности при этом остаются на месте.

## Цветовые роли и типографика

| Роль | Значение |
| --- | --- |
| Основное действие, выбранный раздел | `#0062FF` |
| Наведение основного действия | `#0046E2` |
| Подложка выбранного элемента | `#EBF3FF` |
| Основной текст | `#24364F` |
| Вторичный текст | `#5D6D85` |
| Границы | `#E2E8F0` |
| Рабочий фон | `#F5F7FA` |
| Положительная экономия | `#087B55` |

Синий обозначает действие или выбор. Зелёный используется для положительной разницы и набранного объёма, а не для обещания исполненной сделки. Предупреждения и отрицательная разница выделяются отдельной тёплой палитрой.

Локальный Golos Text содержит кириллицу. Основной текст 13–14 px, пояснения 11–12 px, названия товаров 14–18 px, заголовок раздела 27–34 px, суммы 23–39 px. Числа используют табличную ширину. Вес 400 для текста, 500 для сумм и компонентов, 600 для главных заголовков.

Интервалы: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px. Кнопки и поля имеют собственную единую геометрию. Основные кнопки высотой 44 px; иконки на узком экране получают отдельные доступные названия.

## Состояния компонентов

| Компонент | Поведение |
| --- | --- |
| Основная кнопка | Синий фон; при наведении более глубокий цвет и лёгкая тень; при нажатии короткое уменьшение |
| Вторичная кнопка | Белая поверхность и нейтральная граница; при наведении светлая подложка |
| Поле | Постоянная подпись; видимая рамка фокуса; ошибка рядом с полем и `aria-invalid` |
| Карточка товара | Чёткий выбор через границу, подложку, текст действия и `aria-pressed`; наведение приподнимает карточку |
| Избранное | Отдельная кнопка с состоянием; не изменяет введённое количество |
| Подборка и вид каталога | Активное состояние доступно визуально и через `aria-pressed` |
| Подсказка иконки | Доступна при наведении и клавиатурном фокусе |
| Пустая подборка | Объяснение причины и действие для продолжения |
| Недопустимый объём | Пояснение ошибки; переход к подтверждению заблокирован, в том числе при смене вкладки условий |
| Диалог | Фокус внутри слоя, блокировка фона через `inert`, возврат фокуса после закрытия |

В статическом прототипе нет сетевой загрузки. Состояния серверного ожидания и ошибок API предстоит реализовать при подключении бэкенда, не имитируя существование интеграции.

## Карта движения

| Событие | Движение |
| --- | --- |
| Наведение кнопки и иконки | 150–250 ms, небольшое смещение или изменение поверхности |
| Наведение карточки | Подъём на 3 px и короткая реакция иллюстрации |
| Переход раздела | Постоянная оболочка; индикатор за 300 ms переходит к выбранному пункту |
| Первое появление карточек | 280 ms с задержкой до 150 ms; без повторного каскада на каждом символе поиска |
| Выбор закупки | Обновляется область расчёта, а не вся оболочка |
| Изменение количества | Суммы и объём обновляются на месте |
| Открытие условий | Выдвижение панели за 350 ms |
| Закрытие слоя | Короткий выход за 180 ms с защитой от быстрого повторного открытия |

Ускорение входа `cubic-bezier(0.05,0.6,0.2,1)`. Непрерывных декоративных циклов нет. `prefers-reduced-motion` отключает движение в CSS и JavaScript. Изменение представления каталога сохраняет сам DOM-элемент поля и незавершённый ввод.

## Адаптивность

| Ширина окна | Композиция |
| --- | --- |
| От 1440 px | Навигация 216 px с названиями разделов |
| 720–1439 px | Компактная панель 82 px с иконками, счётчиками и подсказками |
| От 1180 px | Каталог и закреплённый расчёт рядом |
| 960–1179 px | Каталог в три колонки; выбор открывает условия |
| 520–959 px | Каталог в две колонки |
| До 519 px | Крупные карточки в одну колонку; доступен компактный список |
| До 719 px | Верхняя панель и нижняя навигация; панель условий на всю ширину |

Высота закреплённого расчёта учитывает его положение, прокрутку, размер окна и загрузку шрифтов. Основное действие находится в отдельном непрокручиваемом подвале, подробности прокручиваются внутри. Широкие таблицы имеют собственную горизонтальную прокрутку.

## Файлы и проверка

- `dist/styles/tokens.css`: цвета, интервалы, движение и локальные шрифты.
- `dist/styles.css`: единая точка подключения стилей.
- `dist/styles/interface.css`: оболочка, каталог, расчёт, адаптивность и интерактивные состояния.
- `dist/styles/workflows.css`: заявки, формы, диалоги, таблицы и вспомогательные компоненты.
- `dist/js/motion.js`: переходы слоёв и уменьшение движения.
- `dist/js/app.js`: компоненты и сценарии.
- `dist/js/store.js`: локальные данные и настройки интерфейса.

Автоматические проверки покрывают арифметику, фильтрацию, согласование, заявки, отмену, потребности, аналитику, сохранение ввода и настроек после перезагрузки. Проверены синтаксис CSS/JS и наличие локальных ресурсов.

Визуальная проверка собственного интерфейса в браузере заблокирована инфраструктурой предпросмотра. DOM-проверки не подтверждают геометрию на реальных устройствах и плавность движения. Перед демонстрацией требуется просмотр на целевых экранах.

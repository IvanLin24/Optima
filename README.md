# Оптима. Фронтенд совместных закупок

Интерактивный прототип раздела бизнес-банкинга в визуальном направлении ВТБ. Продукт объединяет подтверждённые потребности компаний, сравнивает индивидуальную стоимость закупки и позволяет согласовать участие в группе.

Это самостоятельная концепция для Академии Финтеха. Сайт не является официальным сервисом ВТБ. Реальные счета, платежи, банковская подпись и блокчейн не подключены. Все демонстрационные компании, условия и цены вымышлены.

## Быстрый запуск на Windows

Для запуска нужны Python 3 и браузер. Файлы приложения находятся прямо в корне репозитория.

Если проект уже скачан, откройте терминал в папке `Optima-Git`:

```powershell
cd "$env:USERPROFILE\Optima-Git"
py -3 run_local.py
```

Можно также открыть `START_WINDOWS.bat`. Браузер откроется автоматически; окно сервера оставьте работающим.

При первом скачивании:

```powershell
git clone --branch frontend --single-branch https://github.com/IvanLin24/Optima.git "$env:USERPROFILE\Optima-Git"
cd "$env:USERPROFILE\Optima-Git"
py -3 run_local.py
```

В macOS выполните `python3 run_local.py` из корня проекта или откройте `START_MAC.command`.

Не открывайте `dist/index.html` двойным щелчком: ES-модули требуют локальный HTTP-сервер.

## Обновление проекта

Из терминала в корне проекта:

```powershell
git pull --ff-only
```

После обновления нажмите **Ctrl+F5** в браузере. Для обычных изменений HTML, CSS и JavaScript перезапуск сервера не требуется.

Если ваша копия ещё использует старый адрес `Repository-1`, один раз выполните:

```powershell
git remote set-url origin https://github.com/IvanLin24/Optima.git
```

После переноса файлов из вложенной папки `optima` в корень остановите старый сервер через **Ctrl+C**, перейдите в `Optima-Git`, выполните `git pull --ff-only` и запустите `py -3 run_local.py`. Повторно скачивать проект не нужно.

## Запуск

Для приложения не нужны сборка, CDN или npm-зависимости:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. Можно разместить `dist` на любом статическом хостинге. Запуск через file:// не поддерживается из-за ES-модулей.

Для тестов:

```sh
npm ci
npm run check
```

## Рабочее пространство

На компьютере список предложений и расчёт выбранной закупки расположены рядом. Можно изменить объём и сразу увидеть стоимость с доставкой, экономию и состояние группы. На небольшом экране строка открывает условия. Навигация и форма расчёта сохраняются при обновлении соответствующих данных.

Четыре рабочих раздела, подборки по потребностям и избранному, поиск, категории, сортировка, согласование участия, заявки и аналитика. Внешние шрифтовые сервисы и сборка для запуска не требуются. Клавиша `/` переводит фокус в поиск; Escape закрывает диалог. Поддерживается уменьшение движения.

Система описана в `docs/DESIGN-SYSTEM.md`, исследование в `docs/DESIGN-RESEARCH.md`, лицензии в `docs/THIRD-PARTY.md`, история в `docs/CHANGELOG.md`. Браузерный предпросмотр в среде разработки заблокирован инфраструктурой; автоматические DOM-проверки не подтверждают геометрию на всех устройствах.

## Работающие сценарии

- Уже открытый сервис «Оптима»: предложения, мои закупки, потребности и аналитика. Постоянная навигация на компьютере и нижняя панель на телефоне ведут в одни и те же рабочие разделы.

- Подборка из шести предложений, поиск, категории, сортировка, избранное.
- Карточка закупки в боковой панели. Изменение количества и немедленный пересчёт стоимости, доставки, экономии и порога группы.
- Сравнение самостоятельной и совместной закупки с объяснением всех сумм.
- Подтверждение версии условий, создание локальной заявки, сохранение после перезагрузки.
- Статусы «Сбор группы», «Объём набран», «Отменена». Отказ и повторное присоединение.
- Потребности: ручное добавление и импорт CSV/JSON с проверкой полей и календарной даты. PDF/OCR не имитируются.
- Сопоставление потребности по наименованию, точной спецификации, единице и сроку. Цена из потребности учитывается при сравнении.
- Аналитика по данным текущей подборки и выгрузка CSV. Экспорт согласованных условий заявки в JSON.
- Уведомления, журнал действий, справка, описание данных, сброс демонстрации.
- Адаптивный интерфейс, клавиатурный фокус, модальные диалоги, режим уменьшенной анимации.

## Структура

- `dist/index.html`, `styles.css`, `styles/`: оболочка, общие токены и адаптивное оформление.
- `dist/js/app.js`: экраны, постоянная оболочка и взаимодействия.
- `dist/js/motion.js`: переходы и уменьшение движения.
- `dist/js/data.js`: изолированные демонстрационные данные.
- `dist/js/domain.js`: расчёт и валидация, без зависимости от DOM.
- `dist/js/store.js`: локальное состояние.
- `dist/js/icons.js`: SVG-иконки и иллюстрации товаров.
- `dist/assets/fonts/`: локальные шрифты Golos Text и лицензия SIL OFL 1.1.
- `docs/API-CONTRACT.md`: данные и точки подключения сервера.
- `docs/DESIGN-RESEARCH.md`: визуальные источники и границы соответствия.

## Ветки и история

- `main` — актуальный проверенный срез проекта, который открывается на главной странице репозитория.
- `frontend` — рабочая ветка интерфейса.
- `backend` — рабочая ветка серверной части.
- Сообщения коммитов пишем на русском. Небольшие изменения сохраняем обычными коммитами; номера версий используем для согласованных крупных этапов.
- История сохраняется. Опубликованные изменения отменяем отдельным коммитом без переписывания истории.

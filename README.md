# Оптима

Сервис совместных закупок для малого и среднего бизнеса. Компании объединяют совместимые потребности, чтобы получить условия крупной закупки, приобретая необходимое каждому количество товара.

Сейчас в репозитории находится интерактивный фронтенд-прототип для проекта Академии Финтеха. Интерфейс разработан с учётом предполагаемой интеграции в бизнес-банкинг ВТБ. Данные демонстрационные; банковские API, реальные платежи и смарт-контракты пока не подключены.

## Запуск на Windows

Для запуска нужны Python 3 и браузер. Приложение находится в папке [optima](optima/).

Если проект уже скачан через Git, откройте терминал в его папке и выполните:

```powershell
cd optima
py -3 run_local.py
```

Если терминал уже открыт внутри папки `optima`, достаточно последней команды. Можно также открыть `optima/START_WINDOWS.bat`. Браузер откроется автоматически; окно сервера оставьте работающим.

При первом скачивании:

```powershell
git clone --branch optima-vtb-frontend --single-branch https://github.com/IvanLin24/Optima.git "$env:USERPROFILE\Optima-Git"
cd "$env:USERPROFILE\Optima-Git\optima"
py -3 run_local.py
```

## Обновление существующей копии

Один раз после переименования репозитория обновите его адрес:

```powershell
git remote set-url origin https://github.com/IvanLin24/Optima.git
```

Дальнейшие обновления из терминала проекта:

```powershell
git pull --ff-only
```

После обновления нажмите **Ctrl+F5** в браузере. Для правок HTML, CSS и JavaScript перезапуск локального сервера не требуется. Повторно скачивать проект не нужно.

## Возможности прототипа

- Предложения совместных закупок: поиск, категории, сортировка и избранное.
- Расчёт стоимости с доставкой и сравнение с самостоятельной закупкой.
- Просмотр условий, подтверждение участия, локальные заявки и отмена участия.
- Добавление закупочных потребностей и импорт CSV/JSON.
- Аналитика, выгрузка данных и сохранение состояния в браузере.

## Ветки и изменения

- `main` — актуальный проверенный срез проекта, который открывается на главной странице репозитория.
- `optima-vtb-frontend` — рабочая ветка фронтенда; существующая локальная копия продолжает получать обновления из неё.
- Сообщения коммитов пишем на русском. Небольшие правки сохраняем обычными коммитами; номера версий используем для согласованных крупных этапов.
- История сохраняется. Для отмены опубликованных изменений используем отдельный коммит отмены, без переписывания истории.

Для запуска приложения Node.js и npm не требуются. Для разработки и проверок из папки `optima` выполните `npm ci`, затем `npm run check`.
